EMToa.st: The Successor to EMToast.com

By EMToast Staff
April 27, 2026

The EMToast project has launched https://emtoa.st as its new primary domain, retiring the original emtoast.com address. The domain change closes a multi-year infrastructure overhaul aimed at keeping the project online and independent for the long term.

It was right there in the name

The .st domain wasn't a hard choice — it's already at the end of EMToa**.st**. The new address replaces emtoast.com, which the project ran from 2008 to 2023 and no longer controls.

No single point of failure

EMToast now runs as a distributed network of independent static sites across Cloudflare, Netlify, and GitHub — absurd world news, art, curious ideas, odd products, and short fiction, all of it mirrored in parallel. No single platform failure takes it down.

EMToast Classic: 15 years, preserved

The original 2008–2023 archive has been spun off as EMToast Classic — a standalone static site mirrored across Cloudflare, GitHub, and Neocities. Fifteen years of "F@cked Up Toast" history, protected from link rot and the general entropy of the web -- including comments!

The mission, unchanged

EMToast is a nonsensical publication that has been writing what it wants, when it wants, since 2008. The infrastructure has changed. The mission hasn't.
